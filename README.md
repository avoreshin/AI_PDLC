# AI-FIRST :// PRACTITIONER.GUIDE

Интерактивная презентация в cyberpunk-стиле о практике AI-first разработки.
Это статический сайт без сборки и зависимостей — один самодостаточный
`index.html` со встроенными CSS и JS. Внешние ресурсы только два: шрифты с
[Fontshare](https://www.fontshare.com/) по CDN и картинки из `assets/`.

## Структура

```
.
├── index.html          # Главная презентация (39 слайдов), редактируемая
├── slides/             # 4 самостоятельные презентации
│   ├── commands-build.html
│   ├── harness-operation.html
│   ├── sdd-howto.html
│   └── vision-2029.html
└── assets/             # Изображения и графика (svg, png, img/)
```

Каждый файл презентации открывается независимо.

## Запуск локально

Самый простой способ — открыть `index.html` двойным кликом в браузере.

Чтобы корректно подгружались картинки и шрифты (без CORS-ограничений
`file://`), лучше поднять локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Навигация по слайдам

| Действие | Управление |
|----------|-----------|
| Следующий слайд | `→`, `↓`, `PageDown`, `Space`, свайп вверх, колесо мыши вниз |
| Предыдущий слайд | `←`, `↑`, `PageUp`, свайп вниз, колесо мыши вверх |
| Первый / последний | `Home` / `End` |
| Перейти к слайду | клик по точкам навигации справа |

Переключение слайдов работает через нативный CSS scroll-snap. Если контент
слайда не помещается на экране (узкий или низкий вьюпорт), его можно
проскроллить **внутри** слайда — колесом или свайпом; на краю жест передаётся
переходу к соседнему слайду.

## Режим редактирования

Презентацию можно править прямо в браузере:

- **`E`** — включить/выключить режим редактирования (или навести курсор в
  правый верхний угол и нажать кнопку `✎`).
- В режиме редактирования любой текст на слайде кликабелен и редактируется
  на месте.
- Правки автоматически сохраняются в `localStorage` браузера (с debounce,
  чтобы ввод не лагал) и восстанавливаются при следующем открытии.
- **`Ctrl/Cmd + S`** — экспортировать текущую версию в отдельный HTML-файл
  (`AI-FIRST-GUIDE.cyberpunk.html`) уже с внесёнными правками.

> Правки хранятся локально в этом браузере и привязаны к порядку текстовых
> полей. Чтобы поделиться версией с правками — используйте экспорт (`Ctrl+S`).
